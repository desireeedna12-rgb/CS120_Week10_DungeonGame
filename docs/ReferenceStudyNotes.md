\## What I noticed



| Area | Observation | Why it matters |

|---|---|---|

| Screen or interface | The games use simple menus, score displays, lives, and clear game screens. | A clean interface helps players quickly understand the game and focus on gameplay. |

| User or player action | Players move with the keyboard, collect items, avoid obstacles, and earn points. | These simple mechanics make the games easy to learn and enjoyable to play. |

| Data or state | The games track score, player lives, and game progress throughout gameplay. | Managing game data allows the player to receive feedback and track progress. |

| Asset or media | The games use colorful graphics, sprites, sound effects, and background images. | Visual and audio assets improve the overall player experience and create an engaging game world. |

| Code or project structure | The projects separate game logic, graphics, scoring, and user input into organized sections. | Good organization makes the code easier to understand, maintain, and expand. |



\## Keep, change, or replace



| Element from the reference | Decision | Reason | Update to my Development Document |

|---|---|---|---|

| Simple keyboard controls | Keep | Easy for players to learn and use. | Continue using keyboard movement for the player. |

| Score and lives system | Keep | Gives players goals and provides feedback. | Include score tracking and wave icons for player lives. |

| Retro pixel graphics | Replace | I want a colorful tropical theme instead of pixel art. | Use custom beach-themed artwork and backgrounds. |

| Standard collectibles | Change | I want collectibles that match the island setting. | Replace coins with Seashells and Crystal Wave Charms. |

| Generic game menus | Replace | I want custom menus that fit the game's theme. | Create tropical-themed main menu, victory, and game over screens. |



\## Questions to investigate



1\. How can I detect collisions between the player and collectibles?

2\. What is the best way to update the score and lives while the game is running?

3\. How should I organize the project so it is easy to add more levels or features later?



\## My revised direction



After studying the retro game examples, I decided to keep the simple gameplay mechanics, keyboard controls, score tracking, and lives system because they make the game easy to understand and enjoyable to play. I will replace the retro visual style with a colorful tropical island theme featuring original backgrounds, beach-themed collectibles, and custom interface screens to create a unique experience while following the same core gameplay principles.
