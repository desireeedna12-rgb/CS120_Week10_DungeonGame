# Project Summary

**Stitch & Angel: Island Stack** is a tropical-themed retro puzzle game developed using Visual Basic WPF (.NET). Players begin by choosing either Stitch or Angel before arranging falling tropical puzzle pieces to clear rows, earn points, and survive as long as possible. As rows are cleared, a Friendship Meter fills, allowing players to activate special island-inspired power-ups. The game features original tropical artwork, sound effects, score tracking, and custom user interface elements while demonstrating object-oriented programming, event-driven programming, user interface design, Git version control, and software documentation.

---

# How to Open and Run the Project

1. Open the project using **Visual Studio 2022**.
2. Make sure the **.NET Desktop Development** workload is installed.
3. Open the solution located in the **src** folder.
4. Press **Start (▶)** or **F5** to build and run the project.
5. The application opens to the Title Screen.

---

# Controls

- **Mouse Click** – Select Stitch or Angel
- **Left Arrow** – Move puzzle piece left
- **Right Arrow** – Move puzzle piece right
- **Up Arrow** – Rotate puzzle piece
- **Down Arrow** – Drop puzzle piece faster
- **Space Bar** – Activate a Friendship Meter power-up

---

# Gameplay

- Launch the application.
- Select **Play** from the title screen.
- Choose either Stitch or Angel.
- Arrange falling tropical puzzle pieces.
- Complete rows to earn points.
- Fill the Friendship Meter.
- Activate special power-ups.
- Continue playing until the puzzle pieces reach the top of the board.
