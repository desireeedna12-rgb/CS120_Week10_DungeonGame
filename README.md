# Project summary

Lilo & Stitch: Island Adventure is a tropical-themed 2D game developed using Visual Basic WPF (.NET). Players choose either Stitch or Angel before exploring a colorful island, collecting magical beach-themed collectibles, earning points, and avoiding obstacles. The game features custom artwork, score tracking, wave icons representing player lives, and unique Victory and Game Over screens. This project demonstrates object-oriented programming, event-driven programming, user interface design, Git version control, and software documentation.

---

# How to open and run the project

1. Open the project using **Visual Studio 2022**.
2. Make sure the **.NET Desktop Development** workload is installed.
3. Open the solution located in the **src** folder.
4. Press **Start (▶)** or **F5** to build and run the project.
5. The application opens to the main game window where gameplay begins.

---

# Controls or main workflow

- Launch the application.
- Start the game.
- Select either Stitch or Angel.
- Move the player using the keyboard.
- Collect Seashells and Crystal Wave Charms to earn points.
- Avoid obstacles to preserve player lives.
- Reach either the Victory screen or the Game Over screen.
